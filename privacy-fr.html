Politique de confidentialité

Imperium Gym est conçue pour laisser le contrôle des données à l’utilisateur.

01 / Données locales

Le profil local, le code PIN et les séances sont enregistrés sur l’appareil. Ces données ne sont pas envoyées à un serveur en mode local.

02 / Synchronisation cloud

La synchronisation cloud est facultative. Après connexion, les séances peuvent être enregistrées pour être synchronisées entre appareils.

03 / Contrôle et suppression

Vous pouvez supprimer les données locales depuis les réglages du téléphone. Pour supprimer des données cloud, utilisez la page de support.
